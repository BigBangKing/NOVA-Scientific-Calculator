Privacy policy.

1. Information handled by the Android app

The source version of NOVA is designed to work without an app account or a network connection. It does not request Android internet, location, contacts, camera, microphone or broad shared-storage permissions. The source package does not include an advertising or analytics SDK.

When you create and save a custom calculator, the app stores its name, description, two input labels, formula, example values and result label locally in Android private app preferences. Calculations take place on your device. The current source package does not operate a developer-controlled cloud account or backend to receive these entries.

2. Permissions and local storage

The app saves user-created calculator templates in its private local storage. Its packaged Android manifest disables application backup. The app uses Android's document picker for files you explicitly choose to import and Android's FileProvider for files it prepares to share. It does not ask for unrestricted access to the device's shared storage.

3. Sharing files and results

If you choose to share a custom calculator or result image, NOVA creates an export in its private cache and opens Android's standard sharing interface. Information is transferred to another app or service only when you choose a destination. That destination's own privacy practices apply. If you import a calculator, NOVA reads the file you select to create a local template.

4. Retention and deletion

Saved calculators remain in the app's local storage until you delete them within the app or clear/uninstall the app. Cached shared files may remain until cleared by the app or Android. This source version has no server-side account records to delete.

5. This website

This website is a static project showcase. Its included HTML, CSS and JavaScript do not set cookies, load third-party analytics, run advertising scripts, or collect information through forms. Its screenshots and fonts are served as local website assets.

If you publish it with GitHub Pages, GitHub acts as the website host and may process technical request information, such as IP addresses and browser/device data, under its own policies. See GitHub's Privacy Statement. If you later add a contact form, analytics, external fonts, embeds or another hosting service, update this section.

6. Security and limitations

Local processing reduces the need to transmit calculator inputs to an app-operated service; it does not guarantee protection against access to your device, the destination apps you choose when sharing, or information you publish yourself. Avoid including sensitive personal data in calculator names or files you plan to share.

7. Children

NOVA is a general-purpose calculation utility. The source edition is not designed to collect children's personal information. The publisher should verify the applicable audience and store-disclosure requirements before distribution.

8. Changes and contact

This policy must be reviewed when the app or website changes, particularly if online services, ads, analytics, crash reporting, account systems or cloud storage are added. Publish the updated effective date when making revisions.
